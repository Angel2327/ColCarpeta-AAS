{# Como se muestra un documento: en lenguaje de persona, nunca de sistema (ver el propio pedido de la tarea). "certificado" y "firma_valida" son dos senales independientes del backend -- esta y las otras macros son la unica decision de presentacion sobre como combinarlas, y viven aqui para no repetirla entre la lista y el detalle. La etiqueta nombra el ORIGEN, no una cualidad: "Certificado"/"Temporal" chocaban con el tipo de documento, que el propio ciudadano escribe a mano ("certificado laboral", "certificado de estudios") -- un mismo documento podia leerse "Certificado" en el tipo y "TEMPORAL" en la etiqueta, o "CERTIFICADO" dos veces con dos significados distintos. "De una entidad"/"Subido por ti" no coinciden con ningun tipo que alguien pueda escribir, asi que ya no hace falta la nota aparte de procedencia debajo del documento (decia lo mismo que la etiqueta nueva dice sola). #} {% macro etiqueta_procedencia(doc) %} {% if doc.certificado %} De una entidad {% else %} Subido por ti {% endif %} {% endmacro %} {% macro etiqueta_firma(doc) %} {% if doc.firma_valida is none %} Sin firma digital {% elif doc.firma_valida %} Firma digital válida {% else %} Firma digital inválida {% endif %} {% endmacro %}
